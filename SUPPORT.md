# Support

## How to get help

1. **Read the docs:** start with [README.md](README.md) (setup, configuration, security model).
2. **Search existing issues:** someone may already have hit the same broker or Lunch Money edge case.
3. **Open an issue:** use [GitHub Issues](https://github.com/osloer-industries/lunch-money-de-invest-sync/issues/new/choose) and the bug form when behavior does not match the README.

Include Node.js version, which broker profile failed (`trade-republic` vs `scalable-capital`), and redacted config
structure (never phone numbers, PINs, or API keys).

## Out of scope

- **Lunch Money product support** — billing, account recovery, and official API policy are handled by Lunch Money.
- **Broker account access** — this tool cannot restore Trade Republic or Scalable Capital sessions for you.
- **Security vulnerabilities** — report privately per [SECURITY.md](SECURITY.md), not via public issues.

## Maintenance expectations

Volunteer / best-effort. There is no guaranteed response time. Pre-1.0.0 releases may change behavior without notice;
see README **Versioning and stability**.
