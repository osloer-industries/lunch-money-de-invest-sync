# Security Policy

Security fixes are applied to the latest version on `main`.

Report vulnerabilities privately at
[GitHub Security Advisories](https://github.com/osloer-industries/lunch-money-de-invest-sync/security/advisories/new).
Do not open a public issue. Include reproduction steps and impact, but replace all credentials and private
identifiers with safe placeholders. You should receive an acknowledgement within five business days.
